NIGHT FALCON — Moonlit Sea Intercept is a night-combat jet campaign for the desktop browser: you are Night-1, newest pilot of the Night Falcon squadron aboard the carrier Kestrel, flying six sorties across one moonlit sea war against the raider fleet of the Crimson Wake. Photorealistic night renders, a real glowing cockpit panel and HUD (altitude, speed, heading always legible), night-lock missile combat with flares and searchlights, a hidden ace called Ghost in the 03:00 finale, seven hangar upgrades, three save slots, and a full WebAudio soundscape — all static files, no network.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
python3 -m http.server 8080 --directory out/game
```

Then open http://localhost:8080 in a desktop browser.
